Programação Web III

Sistemas Embarcados
Trabalhamos com TinkerPad e Arduino, nossas primeiras atividades foram um sistema de semáforos e um
de som, onde aprendemos a usar os componentes básicos, e a programar utilizando o TinkerCad.





Programação de Aplicativos Mobile II
Fomos introduzidos à linguagem de programação React Native, que é desenvolvida no site Expo. Fizemos
pequenas atividades para exercitar a linguagem, dentre elas, uma página de portifólio pessoal.




Internet, Protocolos e Segurança de Sistemas da Informação
Realizamos o curso formativo da cisco sobre Conceitos Básicos de Redes, e aprendemos sobre suas variedades
e aplicações.




Planejamento e Desenvolvimento do Trabalho de Conclusão de Curso
Documentamos os requisitos funcionais e não funcionais do projeto, junto com as regras de negócio.
O projeto de TCC se baseia em um sistema de gerenciamento de laboratórios, integrado a um calendário
escolar feito pelos próprios alunos.
